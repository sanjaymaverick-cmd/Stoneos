# UI/UX testing agent

Run `node scripts/testing/ui-ux-audit.mjs` against an isolated local company after the year-run fixtures and staff are available. Both explicit origins must be loopback by default. For the user's explicitly authorized Oracle synthetic-company audit only, set `STONEOS_ALLOW_SYNTHETIC_ORACLE=yes` and `STONEOS_UI_TOKEN_FILE` to an ignored manifest containing factoryId, api/web origins, role tokens and role usernames. The only accepted remote origin is https://stoneos.duckdns.org. Every role's authenticated factory and username are checked before browser use; a mismatch stops immediately. Never supply an existing company owner token. A persona mapped to another persisted role is reported as a coverage limitation.

Set `PLAYWRIGHT_BASE_URL`, `STONEOS_API_URL`, and `STONEOS_{OWNER,MANAGER,SUPERVISOR,OPERATOR,AUDITOR}_{USER,PASSWORD}` in the process environment. Credentials are never embedded in reports. `STONEOS_ALLOW_DEMO_WRITES=yes` permits the demonstrably local consumable receipt/use workflow; without it the audit remains read-only.

The script discovers every static Next page instead of relying on a stale hardcoded route list. It walks all owner screens and role-relevant screens as manager, supervisor, operator and auditor at 1280×800 and 390×844. It records route restrictions, associated form labels, body overflow, navigation target size, runtime errors and full-page screenshots. Restricted pages are distinguished from working pages. A successfully loaded screen is classified **partial**, never workflow-proven.

The primary stock workflow creates a clearly named synthetic epoxy item, records usage through the real form, and confirms the exact remaining stock through the local API. This data is intentionally retained in the isolated demo company. Other full workflows are proved by the company-year and role/security agents; review their evidence alongside this report. Report generation survives failure, retaining findings gathered before interruption.

Outputs: `var/company-year/ui-ux-module-review.md`, `var/company-year/ui-ux/results.json`, and per-role/per-viewport screenshots. These are ignored local evidence, not production assets. Prioritise inability to complete a valid task, unauthorized forms and whole-page mobile overflow before wording/cosmetic improvements. Do not rewrite the product from page counts alone.
